أنت مهندس برمجيات Senior متخصص في بناء الأنظمة القابلة للتوسع طويلة المدى.

أريد بناء مشروع متكامل باسم:

"مركز أهل الحديث والأثر"

لكن في المرحلة الحالية أريد التركيز على:

* Flutter Frontend
* PostgreSQL Database
* Architecture احترافية
* API Layer جاهزة
* Local/Mock Backend مؤقت
* Admin Panel داخل Flutter

مع تصميم المشروع منذ البداية بحيث يكون:

* قابل لإضافة Python FastAPI لاحقاً بسهولة
* قابل لإضافة Docker لاحقاً بسهولة
* قابل للتحول إلى Production Backend بدون إعادة هيكلة جذرية

بمعنى:
لا أريد حالياً Backend Production كامل ولا Docker Infrastructure، لكن أريد أن تكون المعمارية مهيأة لهما من البداية.
