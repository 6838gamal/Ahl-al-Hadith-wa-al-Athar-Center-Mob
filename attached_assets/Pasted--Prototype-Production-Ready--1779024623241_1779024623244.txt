المشروع الحالي ما يزال Prototype بصري وليس نظاماً حقيقياً Production-Ready، وهذا غير مقبول في المرحلة الحالية.

أريد تحويل المشروع بالكامل إلى نظام عملي واقعي متكامل يعمل ببيانات ديناميكية حقيقية وليس Static أو Mock Data.

يجب تنفيذ جميع التفاصيل التالية بدقة صارمة وبدون اختصارات أو حلول شكلية.

========================
🚨 المطلوب الأساسي
==================

تحويل المشروع من:

* UI Demo
* Mock Data
* Static Screens

إلى:

* Real Working System
* Dynamic Data
* PostgreSQL Connected
* Secure Authentication
* Production-Oriented Architecture

========================
🗄️ قاعدة البيانات الحقيقية
===========================

يجب ربط النظام فعلياً بـ PostgreSQL.

المطلوب:

* إنشاء قاعدة البيانات كاملة
* تنفيذ جميع الجداول
* العلاقات
* الفهارس
* القيود
* UUIDs
* Audit Fields
* Soft Deletes

يجب أن تصبح جميع البيانات:

* ديناميكية
* حقيقية
* مرتبطة بقاعدة البيانات

وليس:

* JSON ثابت
* Mock Services
* Fake Data

========================
🔐 نظام المصادقة الحقيقي

========================
🛡️ الإدارة المخفية
===================

هذه نقطة مهمة جداً.

في شاشة تسجيل الدخول:

أسفل الصفحة يظهر:
"شعار مركز أهل الحديث والأثر"

وعند الضغط عليه:
ضغطتين متتاليتين Double Tap

تظهر نافذة منبثقة Admin Login Dialog تحتوي:

* Username
* Password

وعند نجاح تسجيل الدخول:

يفتح:
Admin Panel

وليس واجهة المستخدم العادية.

المطلوب:

* تنفيذها بشكل احترافي وآمن
* عدم ظهور الإدارة للمستخدم العادي
* Route Protection صارم
* Guards حقيقية

========================
👥 الفصل الجندري الصارم
=======================

يجب تنفيذ الفصل الجندري فعلياً وليس شكلياً.

المطلوب:

* الطالب لا يرى أي بيانات تخص الطالبات
* الطالبة لا ترى أي بيانات تخص الطلاب
* فلترة كاملة للمجموعات
* فلترة كاملة للمحادثات
* منع DM غير المصرح
* حماية من الوصول المباشر عبر Routes

ويجب تنفيذ ذلك:

* منطقياً
* برمجياً
* على مستوى البيانات
* وعلى مستوى الواجهة
